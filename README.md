# 🦀 Дневник обучения языку Rust
Я изучаю язык Rust, это мой "дневник" обучения.

Полноценный курс от основ до погружения в системное программирование.  
Курс разработан для последовательного изучения без скачков и пропущенных концепций.
В качестве итогового проекта разработка простого модуля для ядра.

---

## 🎯 Цели курса

1. **Базовый уровень** — освоить синтаксис, владение памятью, базовые абстракции
2. **Углубленный уровень** — трейты, обобщения, асинхронность, работа с данными
3. **Системное программирование** — применение Rust в системном программировании (Linux)
4. **Практика ядра** — написание и тестирование модуля ядра

---

## 📚 Структура курса

Курс разделён на **4 этапа**, всего **120 занятий** (~40 недель при 3 занятиях в неделю).
